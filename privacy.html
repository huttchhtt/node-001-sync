Privacy Policy

Last updated: November 25, 2026

Purpose

NODE-001-Sync is a personal application that uses rclone to synchronize files between a local Linux workstation and Google Drive.

Data Access and Usage

The application accesses Google Drive files and metadata exclusively for file synchronization, including reading, creating, updating and deleting files as required by the synchronization process.

Data Sharing

Google user data is not sold, shared with third parties or used for advertising.

Data Storage and Security

Files are stored on the owner's local workstation and Google Drive account. Authentication credentials are stored locally by rclone.

Data Retention and Deletion

File retention is controlled by the owner. Access can be revoked at any time through Google Account security settings.

Limited Use

The application adheres to the Google API Services User Data Policy, including the Limited Use requirements.
